# CaregiverNotebook_AI
Caregiver notebook HTML artifact from Claude

Caregiver Notebook for Claude

This HTML artifact helps overwhelmed family caregivers manage medical crises. I built it because I needed it myself.
Designed for phones - because that's what you have in your hand at 2am in the hospital waiting room. Works on any device with Claude access.
What it does:

- Track daily care logs, medications, appointments
- Store important documents (insurance, POA, directives)
- Save insights from Claude chats when you need perspective
- Generate reports and letters
- Keep financial records for reimbursement

All within the Claude interface.

No technical experience required! If you can send a text message, you can use this.
Built by a caregiver, for other caregivers, who are figuring it out as they go.
